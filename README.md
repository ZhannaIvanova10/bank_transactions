# Обработчик банковских транзакций

## Функциональность
- Загрузка транзакций из JSON/CSV/XLSX файлов
- Фильтрация по статусу (EXECUTED, CANCELED, PENDING)
- Фильтрация по валюте (RUB, USD, EUR и др.)
- Поиск по описанию с использованием регулярных выражений
- Подсчет операций по категориям (использует Counter из collections)
- Сортировка по дате (возрастание/убывание)
- Валидация ввода пользователя
- Обработка ошибок
